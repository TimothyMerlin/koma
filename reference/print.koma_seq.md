# Print System of Equations

This function prints an object of class `koma_seq` to ensure the
equations are displayed in a readable format.

## Usage

``` r
# S3 method for class 'koma_seq'
print(x, ...)
```

## Arguments

- x:

  An object of class `koma_seq`.

- ...:

  Additional arguments passed to or from other methods.

## Value

No return value, called for side effects. Prints a formatted
representation of the system of equations to the console, with a section
header followed by each equation on its own line.
